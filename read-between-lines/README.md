# Read Between the Lines

A small internal document portal.

## Running it

```bash
npm install
npm start
```

Then open http://localhost:3000

## Or with Docker

```bash
docker build -t read-between-the-lines .
docker run -p 3000:3000 read-between-the-lines
```

## What's here

A homepage listing four internal documents, each with a download link.
Documents are retrieved directly from the server.

Good luck exploring the portal.
